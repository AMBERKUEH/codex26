## Project description

Peatland fires create haze, carbon emissions, biodiversity loss, and operational damage. PeatCycle AI combines IoT telemetry, weather conditions, satellite/drone observations, and a lightweight multi-agent orchestration loop. Sensor, Vision, and Weather agents run concurrently; Prediction and Recommendation agents aggregate their findings into a deterministic JSON payload for the dashboard. The MVP demo follows one operating story: Block C reaches high risk, the system explains the drivers, recommends raising the water table and dispatching a patrol, then quantifies potentially avoided emissions.

## Codex usage and acceleration

Codex was used to inspect the hackathon plan, translate the product requirements into the command-centre UX, implement the dashboard, build the Node orchestration loop, connect the frontend to `POST /api/analyze-block`, and verify the deterministic specialist-agent tests. The major technical decision was to use a dependency-free Node router with concurrent specialist agents for hackathon reliability, while keeping the state shape compatible with a future FastAPI/LangGraph backend.
